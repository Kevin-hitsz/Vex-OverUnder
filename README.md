# Vex-OverUnder

**VEX 机器人竞赛 - Over Under 赛季代码仓库**

此仓库包含了为 VEX Robotics 竞赛 Over Under 赛季开发的多个机器人控制程序。采用 **C++** 编写，使用 PROS 框架进行开发。项目采用模块化架构，包含完整的底盘控制、自主运动、控制器处理等功能模块。

## 📋 项目信息

- **语言**：C++
- **开发框架**：PROS
- **仓库状态**：已归档
- **创建时间**：2023 年 11 月
- **最后更新**：2024 年 9 月

## 📁 仓库结构

```
.
├── src/                    # 源代码文件
│   └── main.cpp           # 主程序入口
├── include/                # 头文件
│   ├── Ropo*.hpp          # 自定义模块文件
│   ├── RopoControl/       # 控制模块
│   ├── RopoMath/          # 数学库模块
│   ├── RopoSensor/        # 传感器模块
│   └── display/           # 显示模块
├── firmware/               # 固件文件
├── project.pros            # PROS 项目配置
├── Makefile               # 编译配置
├── common.mk              # 通用编译规则
└── compile_commands.json  # 编译命令数据库
```

## 📊 分支文件结构对比

所有主要分支都共享以下核心文件：
- `RopoApi.hpp` - API定义
- `RopoChassis.hpp` - 底盘控制
- `RopoController.hpp` - 控制器事件处理
- `RopoDevice.hpp` - 设备管理
- `RopoPosition.hpp` - 位置跟踪
- `RopoIntaker.hpp` - 吃球机构控制
- `RopoLifter.hpp` - 升降器控制

## 📊 程序执行流程

### 初始化阶段
```
initialize() 
  ├─ 电机初始化
  ├─ 位置系统初始化
  └─ 设备初始化
```

### 自主阶段
```
autonomous()
  ├─ Stage 1: 抓取升降杆下的球
  ├─ Stage 2: 导航并抓取中间球
  ├─ Stage 3-5: 采集其他球
  └─ Stage 6: 触碰升降杆完成任务
```

### 操控阶段
```
opcontrol()
  ├─ 摇杆控制底盘运动
  ├─ L1/L2 按钮控制升降
  ├─ R1 按钮控制夹爪
  └─ R2 按钮控制气动系统
```

## 🎓 技术亮点

1. **模块化设计** - 清晰的命名空间结构，易于维护和扩展
2. **异步任务处理** - 使用 PROS 系统处理复杂并发操作
3. **闭环控制** - 精确的运动反馈与控制
4. **事件驱动** - 按钮事件使用回调机制
5. **位置追踪** - 集成陀螺仪和里程计的位置估计
6. **分支管理** - 不同分支代表了不同机器人所用到的代码
